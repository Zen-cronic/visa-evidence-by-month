# Evidence rules

Read this before choosing photos (Step 3), drafting lines (Step 4) and counting months (Step 6).

## Why these rules

Partner-visa programs differ by country, but most ask for the same three things: photos of the couple together over time, a short description of each photo, and documents that show a shared life. The worked example is Canada's spousal and common-law sponsorship. Its document checklist asks for up to 20 photos showing the relationship is genuine, each described, and common-law partners must show at least 12 continuous months together. Checklists change. The Skill never claims a pack meets a program's rules; the couple checks the current official checklist.

## Choosing photos

Work only from the real list of photos that show both partners.

1. Drop photos with no capture date. List them as "date unknown".
2. Group the rest by month.
3. Pass 1: pick one photo per month, oldest month first, until every month that has photos has one or the limit is reached.
4. If more months have photos than the limit allows, spread the picks evenly across the whole period instead, always keeping the first and the most recent month.
5. Pass 2: if slots are left, add photos from places not yet shown, then from months with many photos.
6. Never fill the limit with near-identical shots from the same day.
7. Never pad. If fewer photos qualify than the limit, keep the smaller number and report it.

## Labelling each line

Every line has four fields, each tagged with where it came from:

| Field | Source | Label |
|---|---|---|
| Date | photo capture date in metadata | `from metadata` |
| Place | location name or GPS in metadata | `from metadata`, or `unknown` if missing |
| People | the two confirmed person names | `from Photos people` |
| Context | visual description of the photo | `[confirm]` until the user confirms or edits it |

The context is a suggestion only. A visual description can say "two people at a restaurant table" but cannot know it was an anniversary dinner. Only the user can add that. Lines not confirmed are saved as `[not confirmed]`, never as fact.

## Counting months

- The period runs from the relationship start month to the current month.
- A month is **covered by a photo** when any both-partner photo (chosen or not) has a capture date in that month.
- A month is **covered by a document** when a joint document that names both partners is dated in that month, or its period includes it.
- Report the two kinds of coverage separately, so the couple can see where they rely only on photos.
- A **gap** is a month with neither. Consecutive gap months are grouped: "no evidence: March to June 2025".
- For common-law couples, the gap list shows at a glance whether the most recent 12 months are continuous. The Skill states the facts only; it does not say whether a program will accept them.

## Joint documents

Useful kinds: a lease or mortgage with both names, utility or internet bills, insurance policies, bank statements, official mail to the same address. Keep only documents that name both partners. If names or addresses differ between documents (a spelling, an old address), note it in the index without changing anything; the couple may need to explain it.
